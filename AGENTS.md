# Project Guidelines

- Read the relevant documentation in `docs/` before implementing any task.
- Follow `docs/PRD.md` for product requirements.
- Implement only the requested task; do not implement future features.
- Do not refactor unrelated code.
- Follow Laravel conventions and existing project patterns.
- Preserve existing behavior unless the requested task explicitly changes it.
- Run relevant tests after changes (use `php artisan test` or a targeted test filter).
- Report changed files, tests run, and any failures or tests not run with reasons.
